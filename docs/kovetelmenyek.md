# Követelmények és feladatok (05. Projekt)

Forrás: a képzési program 05. Projektje, „Kis-közepes vállalati hálózat tervezése, megvalósítása ipv4 címzéssel és egytáblás adatbázis tervezése, kivitelezése, módosítása, lekérdezések” (11. évfolyam, 80-120 óra, 2-4 fős csoport).
